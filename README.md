# Сайт-портфолио Виктории Цвых

Одностраничный сайт-резюме: HTML + CSS + JavaScript, без сборки и зависимостей.

## Структура проекта

| Файл         | За что отвечает                                      |
|--------------|------------------------------------------------------|
| `index.html` | Содержимое: тексты, секции, контакты                 |
| `style.css`  | Внешний вид: цвета, шрифты, отступы, адаптивность    |
| `script.js`  | Поведение: меню на телефоне, анимации, год в подвале |

## Как редактировать

- **Тексты и проекты** — только в `index.html`. Каждый блок подписан
  комментариями вида `<!-- ===== ПРОЕКТЫ ===== -->`. Чтобы добавить проект,
  скопируйте блок `<article class="project">…</article>` и замените текст.
- **Цвета и шрифты** — в начале `style.css` в секции «ПЕРЕМЕННЫЕ». Поменяете
  `--accent` — перекрасятся все ссылки, кнопки и подписи.
- **Отступы** — тоже переменные (`--space-…`), кратные 4px.

## Как посмотреть сайт локально

Просто откройте `index.html` в браузере двойным кликом — ничего устанавливать
не нужно.

## Как опубликовать на GitHub Pages (бесплатно)

1. Заведите аккаунт на [github.com](https://github.com), если его нет.
2. Создайте репозиторий с именем `ваш-логин.github.io`
   (например, `vtsvykh.github.io` — тогда сайт откроется по адресу
   `vtsvykh.github.io`).
3. Загрузите три файла сайта (`index.html`, `style.css`, `script.js`)
   кнопкой **Add file → Upload files** на странице репозитория.
4. Откройте **Settings → Pages**, в разделе Build and deployment выберите
   **Deploy from a branch**, ветка `main`, папка `/ (root)`, нажмите Save.
5. Через пару минут сайт будет доступен по адресу `ваш-логин.github.io`.

Любое изменение на GitHub: **Add file → Upload files** (или редактирование
через карандаш у файла) → Commit changes — сайт обновится сам.
